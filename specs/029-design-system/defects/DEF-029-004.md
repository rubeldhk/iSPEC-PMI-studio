# DEF-029-004 — two pairs of controls share one accessible name on the project surface

**Originating task**: T885 (found by the machine-observable half of the keyboard pass)
**Found**: 2026-08-22
**Status**: OPEN — disposition belongs to T904 triage

## Reproduction

Open a project and tab through it. The recorded focus order (verbatim, from the run) contains:

```text
 7. select#requirements-type     — "Type"
 8. select#requirements-priority — "Priority"
...
11. select#requirement-type      — "Type"
12. select#requirement-priority  — "Priority"
```

Stops 7/8 are the **register's filters**; stops 11/12 are the **new-requirement editor's fields**.
Their accessible names are identical.

## Expected vs actual

Expected (`US1`: *"hearing each control announced with a meaningful name"*): a control's announced
name distinguishes it from the others on the page. Actual: a screen-reader user tabbing the page
hears *"Type, combo box"* twice and *"Priority, combo box"* twice, with nothing in the announcement
saying which one filters the list and which one sets the value about to be saved. The visual user
has the surrounding layout and the "New requirement" heading to disambiguate; the announcement
carries neither.

## Why every check passed

`T883`/`T894` assert **zero axe violations**, and axe is right to stay silent: each control *has*
an accessible name, and duplicate names are not a WCAG failure in themselves. The gap is between
"has a name" and "has a name that tells you which control this is" — which is `FR-DS-043`'s
territory (*name things as a user recognises them*), a **SHOULD** deliberately carrying no
mechanical check, because no automated rule can judge whether a name is meaningful.

This is the honest limit of `T888a`: it checks that a *confirmation* says what happened, not that
a *label* is unambiguous in context.

## Suggested remediation (not applied)

Give the filters names that say they filter — "Filter by type", "Filter by priority" — or group
them under a named `fieldset`/`aria-labelledby` region so the announcement carries the grouping.
Either is a task against `FR-DS-042`/`FR-DS-043`, and worth confirming with the human screen-reader
pass (`T885`) before choosing, since which fix reads better is exactly what that pass can judge and
this record cannot.
