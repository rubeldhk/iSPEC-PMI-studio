# DEF-029-002 — horizontal overflow at the minimum viewport under 200% text zoom

**Originating task**: T900a (the Tier 2 reachability run found it; T900 owns the condition)
**Found**: 2026-08-21, by the run-generated reachability transcript — step
`"Requirements page at 360×640 and 200% text zoom"` recorded **488px content in a 360px viewport**
**Status**: RESOLVED (2026-08-21, same run; fix re-measured to `none` in every condition)

## Reproduction

Running application, Requirements page, layout viewport 360×640 (FR-DS-040 minimum), root
font-size 200% (WCAG 1.4.4). `document.documentElement.scrollWidth` = 488 > 360.

## Cause — three layers, found by iterating against the live page

1. A text input's intrinsic width (the default `size` attribute, ~20 characters) does not shrink
   with the viewport; at 32px root font it alone was ~324px wide.
2. `.ds-page`/`.ds-stack` used the implicit grid track, whose min size is the largest child's
   min-content — so the too-wide control widened the whole page rather than being clipped by it.
3. After both fixes, the one-word `Requirements` page-header title (unbreakable) still overhung by
   1.3px.

## Fix (frontend/src/design/components/components.css)

- global `box-sizing: border-box`;
- `.ds-input`/`.ds-select`: `max-width: 100%; min-width: 0`; `.ds-row > *`: `min-width: 0`;
  `.ds-field`: `max-width: 100%`;
- `.ds-page`/`.ds-stack`: `grid-template-columns: minmax(0, 1fr)` — a control's intrinsic width
  may never widen the page;
- `.ds-page-header__title`: `overflow-wrap: anywhere` — at the extreme condition a title breaks
  rather than clips.

## Evidence

`docs/accessibility/EPIC-029-reachability-transcript.md` steps 12–16: 488px → 384px → 362px →
`none` across Projects and Requirements, 100% and 200% zoom, light and dark. The full frontend
suite (228), lint, and typecheck all pass after the fix.

## Why the unit suites could not have caught it

jsdom computes no layout (research R-029-3), so no assertion on scrollWidth is possible there.
This is precisely the class of defect Constitution XI Tier 2 exists to catch, and it was caught on
the first Tier 2 run this Epic performed.
