# DEF-031-005 — SCOPE_ORDER has no repository or path scope (handover, `T795`)

**Epic**: `EPIC-031` | **Raised**: 2026-10-08 | **Status**: DEFERRED to `EPIC-019`
**Originating task**: `T795` · **Severity**: LOW

`EPIC-019`'s `SCOPE_ORDER` is organization / workspace / project / product. `BR-0070` names
*"organization, workspace, project, repository and path scope"*. This Epic does not need the two
missing scopes — a risk class is a property of the action and its target (`FR-DPE-002`), not of a
file path — and records the gap so it is not read as having accepted a narrower `BR-0070`.
