## A false positive worth recording

An automated probe reported **"NO INDICATOR"** for two buttons on Projects — apparently a
`FR-DS-033` failure. It was wrong. The probe used programmatic `.focus()`, which does **not** match
`:focus-visible` on buttons in Chromium; reached by **Tab**, the same buttons match
`:focus-visible` and show the 2px outline.

The design system is doing the *right* thing — no focus ring on mouse click, a ring on keyboard —
and a naive reading of the probe would have filed a defect against correct code. Recorded because
the next person to automate this will hit it too.
